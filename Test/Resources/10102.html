安装&引入库


如果你是手动编译的示例程序 [Test]，请跳过...


打开 [RogalunaRouteCore] ，选择构建所使用的工具包，在构建设置中， [构建的步骤] 下方，点击 [添加构建步骤] ，添加 [install]语句 ，这样一来，CMake 会自动将头文件复制到库目录中（详情见构建文件)，或者你也可以手动进入形如 [Desktop_Qt_6_7_3_MinGW_64_bit-Release] 的目录，在终端/命令提示符界面执行 [cmake --install .]


构建完毕后，查看 [build] 目录下的库目录，将其复制到你的工程中，或直接在你的工程中引入其路径。


在你的工程中引入刚刚编译的库，以下是一个使用CMake的示例：

set(LIB_ROGALUNA_ROUTE_CORE_ROOT ${...库目录路径})

# 查找库文件

find_library(ROGALUNA_ROUTE_CORE_LIBRARY

NAMES RogalunaRouteCore RogalunaRouteCored

PATHS ${LIB_ROGALUNA_ROUTE_CORE_ROOT}/lib

${LIB_ROGALUNA_ROUTE_CORE_ROOT}/bin

NO_DEFAULT_PATH

)

# 查找头文件路径

find_path(ROGALUNA_ROUTE_CORE_INCLUDE

NAMES RogalunaRouteCore_Global.h

PATHS ${LIB_ROGALUNA_ROUTE_CORE_ROOT}/include

NO_DEFAULT_PATH

)


确保CMake编译成功即可使用
