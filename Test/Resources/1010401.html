路由格式


FRouteObject 定义了一种静态路由的形式，注册设置后，就不会改变其内部的值，因此，我们更加需要关注如何有效的注册它。


FRouteObject的构造函数如下：

explicit FRouteObject（

const QString& path,

CreatorFunc creator,

const QString& viewName = QString(),

const QVariantMap& meta = {},

const QVector<FRouteObject*>& children = {},

QObject* parent = nullptr

)


一个 FRouteObject 的示例如下：

FRouteObject("page1", []() -> QWidget* { return new Page1; }, "page_one", {{"redirect", "page1_1"}, ... }, { /** Childrens */}),


第一个参数 path 表示它相对上一级的段名称，比如上一级是 "/home"，那么它的完整路由就是 "/home/page1"

第二个参数 creator 的定义： using CreatorFunc = std::function<QWidget*()> 它表明需要传递一个返回控件指针的函数，通常在其中直接创建控件即可

第三个参数 viewName 是一个附加属性，用来标识创建视图的名称。你可以通过访问视图实例的 IRoutable 接口，得到 FRouteObject 的指针，进而获取当前视图的名称

第四个参数 meta 是元数据，同样是一个附加属性，但是其中可以定义多对键值对，以表达出许多附加属性的效果。上述示例中展示的就是其重定向属性的设置，当设置了这个属性后，在访问 "/.../page1" 后，将直接跳转到 "/.../page1/page1_1"

第五个参数 children 定义了这个路由的子集，你可以在其中添加更多的 FRouteObject 以构建一颗路由树

第六个参数 parent 作为继承 QObject 的传递参数，一般情况下无需填写
