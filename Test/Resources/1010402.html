构建路由对象


为了厘清各个页面的组织关系，使用树形结构描述页面直接的关系就显得直观便捷，有利于开发者进行管理


一颗路由结构树必须包含一个根节点， 固定使用 "/" 表示根， 这个根节点必须被创建，否则路由器无法识别

根节点构建如下：

FRouteObject("/", []() -> QWidget* { return nullptr; }, "", { /** 元数据 */ }, { /** Childrens */}),


在根节点中，可以添加下属路由以创建结构化的视图路由节点：

FRouteObject("/", []() -> QWidget* { return nullptr; }, "", { /** 元数据 */ }, {

FRouteObject("page1", []() -> QWidget* { return new Page1; }, "", { /** 元数据 */ }, { /** Childrens */}),

FRouteObject("page2", []() -> QWidget* { return new Page2; }, "", { /** 元数据 */ }, {

FRouteObject("page2_1", []() -> QWidget* { return new Page2_1; }, "", { /** 元数据 */ }, { /** Childrens */}),

}),


}),


注册的路由节点如果能够创建实体视图（[]() -> QWidget* { return new Page1; } 能够创建视图），即可以通过设置的路由路径进行导航
